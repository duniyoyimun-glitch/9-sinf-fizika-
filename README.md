# 9-Sinf Fizika: Interaktiv Simulyatsiyalar ⚛️

Ushbu loyiha 9-sinf Fizika fanining **Molekulyar-kinetik nazariya (MKT) va Termodinamika** mavzulari bo'yicha tayyorlangan interaktiv ko'rgazmali simulyatsiyalarni o'z ichiga oladi.

## 🚀 Saytni ko'rish
Interaktiv simulyatsiyalarni brauzerda ishlatish uchun quyidagi havolaga o'ting:
👉 [9-Sinf Fizika Simulyatsiyasini Ochish](https://duniyoyimun-glitch.github.io/9-sinf-fizika-/1-mavzu.html)

## 📌 Mavzular va imkoniyatlar:
1. **Termodinamika asoslari:** Porshen ostidagi gaz hajmini o'zgartirish va issiqlik berish simulyatsiyasi.
2. **Ideal gaz tenglamasi:** Gaz molekulalarining idish devoriga urilishi va bosim o'zgarishini kuzatish.
3. **Harorat va kinetik energiya:** Harorat (Kelvin) o'zgarganda molekulalar harakatining sekinlashishi yoki tezlashishi.
